<td width="100%">

### 🌱 Green-Eye — Rice Leaf Disease Detection

**Green-Eye** is an AI-powered system designed to identify rice leaf diseases using deep learning and provide useful agricultural assistance to farmers.

#### ✨ Main Features

* 🌾 Rice leaf disease classification
* 🧠 Lightweight Vision Transformer (**ViT**)
* 🔍 Attention-based model interpretability
* 🤖 AI chatbot for farmer assistance
* 🌐 Django-based web application
* 🇧🇩 Bengali-friendly farmer support

> 🎯 **Goal:** Make AI-powered crop disease detection more accessible and useful for farmers.
